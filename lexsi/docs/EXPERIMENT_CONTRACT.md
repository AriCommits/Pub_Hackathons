# Experiment contract: tooluse_v2

`TaskSpec` is private: oracle, split, group, and tool dependencies stay outside model input. `PolicyInput` is a separate explicit allowlist of public prompt, tool schemas, and observations; callers must populate those fields only with policy-visible data. `ExecutionTrace` records harness events, stopping reason, provenance, model-owned spans and token counts. An adapted historical EventLog is explicitly `legacy_untrusted`: it cannot establish provenance by itself. `VerificationResult` keeps answer and execution compliance separate.

All serialized contracts identify their schema version. Run manifests bind configuration, data, model, fixtures, template, verifier and code revision. `prepare_run` creates an exclusive run directory and returns a secret resume token; store it securely, separate from public artifacts. Resume requires the token and the identical manifest. `snapshot_files` streams SHA-256 hashes without copying weights. The protected artifact inventory should be supplied by the integrator before experiments.

All GPU-owning processes on a host must share one lease directory and acquire `GpuLease` using the detected device UUID. An operating system lock, held for the lifetime of the process, is authoritative; a heartbeat records owner PID and process start time for monitoring. A crashed process releases the lock automatically. Never remove or replace lease files while work is running. Call heartbeat periodically, and hold the lease through training, inference and calibration.

The frozen targets and selection thresholds are in `actproto/configs/experiment_v2.yaml`. They are requirements, not measured results. The final split is reserved for the joint Plan 10 comparison; split access controls are future runner responsibilities, not implemented by this contract alone. Legacy scores retain their original meaning. Subsequent stages must verify calls against trusted execution and enforce the public/private boundary at actual prompt construction.
